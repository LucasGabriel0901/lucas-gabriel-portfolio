Modo de Edição Direto no Código

Como o portfólio está hospedado de forma estática no GitHub Pages, os projetos são gerenciados diretamente nos arquivos.

Como adicionar um projeto:

  1. Salve a foto do projeto na pasta principal.
  2. Abra o arquivo projetos.json.
  3. Copie e cole um bloco de projeto existente.
  4. Preencha os novos dados e o nome exato da foto.
  5. Faça o git push para a nuvem.
